# Kittiwake release notes

## 4.2 (released 2 June 2026)

- Zone-based speed limits can now be scheduled by shift
- Site Console shows battery health per robot
- Fixed: dispatcher could assign two robots to one charger

## 4.1 (released 10 December 2025)

- Supports up to 150 robots per edge server (was 100)
- New public API endpoint for task history

## 4.0 (released 3 March 2025)

- New path planner with dynamic obstacle avoidance
- Heron arm integration (beta)
